Loft 개인정보처리방침

시행일: 2026-10-15 · Loft 소개

Loft 는 사용자가 자기 컴퓨터에서 직접 실행하는 개인용 도구입니다. 개발자가 운영하는 서버가 없으며, 아래의 데이터는 모두 사용자의 컴퓨터와 사용자 본인의 Google Drive 안에서만 처리됩니다.

1. 접근하는 Google 데이터

  • 요청 범위: https://www.googleapis.com/auth/drive.file 하나뿐입니다.
  • 이 범위로 Loft 가 직접 만든 Loft/ 폴더와 그 안의 파일만 만들고, 읽고, 고치고, 지웁니다. Drive 의 다른 파일, 메일, 연락처 등에는 접근하지 않습니다.
  • Drive 저장 공간 사용량을 표시하기 위해 용량 정보(전체·사용량)를 읽습니다.

2. 사용 목적

사용자 본인의 백업을 사용자 본인의 Drive 에 보관하고, 같은 사용자의 다른 컴퓨터에서 내려받기 위해서만 사용합니다. 광고, 분석, 프로필 작성, 모델 학습에는 사용하지 않습니다.

3. 저장과 보호

  • 올리는 백업은 사용자의 컴퓨터에서 암호화된 뒤 전송됩니다. 암호 키는 사용자의 컴퓨터(macOS 키체인)와 사용자가 보관하는 복구 암호에만 있습니다.
  • Google 로그인 토큰은 사용자의 컴퓨터에만 저장되며(권한 600 파일), 개발자에게 전송되지 않습니다.

4. 공유와 제3자 제공

Loft 는 Google 사용자 데이터를 개발자나 제3자에게 전송, 판매, 공유하지 않습니다. 데이터는 사용자의 컴퓨터와 Google Drive 사이에서만 오갑니다.

5. 보관 기간과 삭제

  • 데이터는 사용자가 지울 때까지 사용자의 Drive 에 남습니다. Drive 에서 Loft/ 폴더를 지우면 모두 삭제됩니다.
  • Loft 의 접근 권한은 언제든 Google 계정 › 타사 앱 및 서비스에서 해제할 수 있습니다.

6. Google API 서비스 사용자 데이터 정책

Loft 가 Google API 로 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API Services User Data Policy를 따릅니다.

7. 변경과 문의

이 방침이 바뀌면 이 페이지의 시행일을 갱신합니다. 문의는 GitHub Issues로 남겨 주세요.

Privacy Policy (English summary)

Loft is a personal tool that the user runs on their own computer; there is no developer-operated server. Loft requests only the drive.file scope and accesses only the Loft/ folder and files it created in the user's own Google Drive (plus storage quota information). Data is used solely to store and retrieve the user's own encrypted backups. Backups are encrypted on the user's computer before upload; keys and OAuth tokens stay on the user's computer. Loft does not transfer, sell or share Google user data with the developer or any third party, and does not use it for advertising, analytics or model training. Users can delete all data by deleting the Loft/ folder and revoke access at myaccount.google.com/permissions. Loft's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: GitHub Issues.
