Loft

개인 업무 데이터를 본인 Google Drive 에 암호화해 보관하는 개인용 도구

무엇을 하나요

  • 사용자가 자기 컴퓨터(macOS)에서 직접 실행하는 개인용 도구입니다. 별도의 서버나 계정 가입이 없습니다.
  • 사용자가 자기 컴퓨터에 모은 작업 기록의 백업을 컴퓨터에서 암호화한 뒤 사용자 본인의 Google Drive 에 있는 Loft/ 폴더에 올립니다.
  • 같은 사용자의 다른 컴퓨터에서 그 백업을 내려받아 확인할 수 있습니다.

Google 계정으로 로그인하는 이유

Loft 는 Google Drive API 의 drive.file 범위만 요청합니다. 이 범위로는 Loft 가 만든 파일과 폴더만 읽고 쓸 수 있고, Drive 의 다른 파일은 볼 수 없습니다.

개인정보

Google 사용자 데이터를 어떻게 다루는지는 개인정보처리방침에 적어 두었습니다.

Loft is a personal, self-run macOS tool. It encrypts the user's own work-log backups on the user's computer and stores them in a Loft/ folder in the user's own Google Drive, using only the drive.file scope. See the Privacy Policy.
